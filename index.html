Comparing an unknown glass with the tephra database

Load the Excel database, paste the mean and standard deviation of the unknown, and get a ranking of the compatible units at 1 or 2 sigma. Everything runs in your browser: the file is never uploaded anywhere.

2. Unknown composition

Major and trace elements can be mixed or separate. The decimal separator can be a dot or a comma.

I have the individual analyses (shards)

Upload an Excel or CSV file with the analyses, or paste them below. The first row containing element names is used as the header; other columns (e.g. sample name) are ignored.

3. Criteria

Available after loading.

An element is compatible if the intervals of the unknown and of the unit overlap: |Δ| ≤ k·(σ unknown + σ unit). Zero σ values are raised to 1% of the mean.

4. Input file format

The Excel template follows the English database layout: section labels on row 1, column names on row 2 and one glass analysis per row from row 3. The downloaded template includes real example rows. Replace or remove every example row before adding your own data. Use wt% for major oxides and ppm for trace elements. For an unknown, fill in the measured columns and optionally Sample. Leave unused columns and the normalized block blank. Upload the completed file under “I have the individual analyses (shards)” and select the sheet you filled in.
